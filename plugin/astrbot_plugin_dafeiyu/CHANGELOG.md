# 更新记录

## v1.4.0

- 新增「群里说得短就回得短」（`group_brevity`，默认开）：群里叫她的这句不超过 `short_chars`（默认 15）个字时，请求模型前给这一轮加一句「对方就 N 个字，一条消息接住就行，别拆成好几条」。统计里群里对方说 5 字以内，她回中位 22 字、近四成拆成多条，私聊同样情况只回 13 字。只管有人叫她的那一轮，陪伴插件的主动消息、只发图或表情的不管。
- 新增「说话习惯自检」（`habit_check`，默认开）：每天 `run_at`（默认 04:30）只读数一遍 AstrBot 对话记录里她最近的回复（每个对话取最近 `recent_per_chat` 条，不算调工具那几轮），挑出最突出的最多三处——群里对方说得短时她回多长、拆几条，最常用的开头，反复出现的口头禅，群里的括号动作——写成提醒放进之后每一轮；群里的毛病只在群里提醒。不额外调模型，插件启动时提醒不是今天的也先算一次。上线时算出的是「群里别人只说几个字，你常回 32 字左右、55% 拆成好几条」和「开头老用『行』（26 次）」。
- 这两个提醒和 `reply_direction` 一样用 `mark_as_temp` 加在这一轮的用户内容后面，不存进聊天历史、不动系统提示词。

## v1.3.0

- 发照片（selfie）：「最近发过的」从内存里记 5 张改成按聊天存盘记 10 张（`recent_count`，存在 `data/plugin_data/astrbot_plugin_selfie/sent.json`），重启后也不重复发同一张。另加 `daily_limit`（每个聊天每天最多发几张，默认 0 不限），到了让她自己用口气说今天发够了。

## v1.2.0

- 新增「引用她又 @ 别人时说明在跟谁说」（`reply_direction`，默认开）：AstrBot 只要看到引用了她的消息就算叫她，不管这条另外 @ 了谁，于是「@B 你看她说的」她也当成在问自己。现在她照常可以接话，只在请求模型前给这一轮加一段说明：谁引用了她、@ 的是谁、这句主要是说给谁听的，让她先读懂再接；同时 @ 了她的，说明这句是对他们几个说的。说明用 `mark_as_temp` 加在这一轮的用户内容后面，不存进聊天历史、不动系统提示词。微信要连接器 0.13.0 起才有 @ 别人的消息段。

## v1.1.0

- 表情转换（face）的语音转写和视频理解：百炼 key 改成按 `dashscope_key_providers` 的顺序从几个提供商里借（默认 dashscope_tts → dashscope_embedding → bailian_rerank）。原来只认 dashscope_tts，这个提供商删了以后，收到的语音条和视频一直是「没听清 / 未能识别」。

## v1.0.0

- 把只回私聊、平台提示、表情转换、拍一拍、新人欢迎、发照片、唱歌、发语音 8 个插件合成一个，行为不变；配置从各插件目录里的 config.json 搬进 AstrBot 面板。
- 平台提示的平台名字改成一项一个「平台ID=名字」（面板没有对照表类型的配置）。
- 「草稿清理」的优先级从 0 提到 1，保证合并后仍在记忆插件之前处理。
- 「语音开 / 语音关 / 语音状态」三个指令从表情插件挪到发语音一节，可以单独关。
- 从 AstrNa 1.7.3 搬来过场白隐藏、工具历史压缩、输出字数限制，默认关。
